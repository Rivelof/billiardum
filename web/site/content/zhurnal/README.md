# Статьи журнала (`/zhurnal/`)

Сюда кладутся статьи сайта — по файлу Markdown на статью (решение №140). Имя файла — адрес статьи латиницей: `kak-vybrat-kiy.md` → `/zhurnal/kak-vybrat-kiy/`. Этот README сайт не показывает (имя не подходит под адрес).

Шапка файла:

```
---
title: Как выбрать кий
description: Одно-два предложения для поиска и карточки в журнале
date: 2026-10-20
audience: Игрокам
---
```

`audience` — «Игрокам» или «Владельцам». Разметка: `##` и `###` заголовки, абзацы, списки `- ` и `1. `, `**жирный**`, `*курсив*`, `` `код` ``, `[ссылка](https://…)` или `[ссылка](/dlya-klubov/)`, `> цитата`. Сырой HTML экранируется.

Без выдуманных цифр, клубов и отзывов. Пока папка пуста, на сайте — пустое состояние журнала.
