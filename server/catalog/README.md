# Каталог бара (backend-pos, M2)

Контракт — `docs/contracts/m2.md` §3–§5, решение №76, PRODUCT §5, §16.4. Общее описание бара и кассы — `server/orders/README.md`.

- `api.mjs` — `menuFor(db, {clubId, audience: guest|staff})` (контракт §5): гостю без `is_alcohol`, пока `bl.platform_settings.qr_alcohol_allowed` не `true`; персоналу — всё, с `stock_qty`; `available` — не в стоп-листе и (при `pos_stop_at_zero`) остаток > 0. `resolveItems` — строки заказа со снимком цены и модификаторов: алкоголь гостю — `not_found`, стоп-лист — `stop_list`, модификаторы только из групп товара в пределах `min_select`/`max_select` (без выбора — по умолчанию).
- `service.mjs` — категории, товары, группы модификаторов и модификаторы (управляющий и выше; стоп-лист — `setStopList`, ресепшн и выше, №88), удаления нет (`active: false`), журнал `catalog.*` с изменениями «было → стало»; импорт CSV атомарно, обновление по `sku`, иначе по категории и названию.
- `csv.mjs` — разбор CSV: «,» или «;», кавычки, BOM, русские и английские заголовки (`категория|category`, `название|name`, `цена|price` в рублях, `ед|unit`, `алкоголь|is_alcohol`, `ндс|vat_code`, `предмет|payment_subject`, `артикул|sku`, `описание`, `фото`, `стоп`, `склад`); ошибки — `[{line, field, code}]`.
- `xlsx.mjs` (M5.1 №157) — импорт из Excel без зависимостей: zip (`lib/unzip.mjs`) и XML первого листа и `sharedStrings`; строки идут в тот же разбор, что CSV (`rowsToProducts`), номер строки — строка листа. Формулы не вычисляются (берётся сохранённое значение), макросы, внешние ссылки, стили и картинки не распаковываются, DOCTYPE — отказ. Лимиты: файл 2 МБ, распакованное 20 МБ, 5 000 строк (`too_many_rows`). Испорченный файл или zip-бомба — `400 xlsx_invalid`.
- `POST /api/clubs/{club}/catalog/import`: JSON `{csv, dry_run?}` как раньше; или файл телом (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `text/csv`, `application/octet-stream`) с `?dry_run=1`; или `multipart/form-data` (`file`, `dry_run`). `.xlsx` узнаётся по сигнатуре zip. Ответ дополнен `source` (`csv`|`xlsx`), `total` (строк товаров) и при `dry_run` — `rows`: все строки плана `{line, action: create|update, category, name, price_kopecks, unit, is_alcohol, sku}` (и для CSV).
- Сеть (M5.5 №191, `server/networks/README.md`): товар из шаблона меню сети — `network_product_id`, `network_override` в `productView`. Поля шаблона (`MENU_TEMPLATE_FIELDS`: категория, название, описание, артикул, цена, единица, алкоголь, НДС, предмет, `active`) у такого товара: «жёсткий» шаблон — `409 network_locked`, импорт — ошибка строки `network_template` (импорт не применяется, видно в предпросмотре); «мягкий» — можно, товар становится переопределённым. Алкоголь шаблона клуб не снимает ни в каком режиме. Стоп-лист, склад, фото, порядок, модификаторы — клуб ведёт сам.
- Фото — путь сайта (`/media/…`) или `https://` (загрузки файлов в M2 нет).

Маршруты — `api/routes/catalog.mjs`. Тесты — `server/catalog/test/csv.test.mjs`, `server/orders/test/db/catalog.test.mjs`.
