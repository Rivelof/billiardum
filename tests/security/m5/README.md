# tests/security/m5 — PoC M5.1 «Подключение клуба без выезда»

Pentester. Проверка затрагивает деньги (магазины, проверочные платежи), вход (создание клуба),
протокол (привязка), журнал и свет.

## Запуск

```
BASE=https://localhost:8443 bash tests/security/m5/poc.sh
```

- `poc.sh` — батарея: лимит клубов (гонка), чек-лист, режимы без platform_admin, изоляция клубов,
  маска секрета, разбор `BLD1:`, перебор кода привязки, импорт `.xlsx` (XXE / billion laughs /
  zip-бомба / zip-slip), тарифы (отрицательная/нулевая цена, дыра), права ресепшена/постороннего.
- `mkxlsx.mjs` — генератор вредоносных `.xlsx` (`node mkxlsx.mjs <xxe|laughs|unknownent|bomb|slip> out.xlsx`).

Правила стенда: только локальное окружение, телефоны `+7999650xxxx`, свои новые клубы,
столы 1–8 и клуб сида не трогаются, без DoS. К базе и секретам скрипты не обращаются.

## Итог

Эксплуатируемых находок нет. Защиты держатся. Единственное наблюдение — приём тарифа с ценой 0 ₽/час
(низкая важность, см. `REPORT.md`).
