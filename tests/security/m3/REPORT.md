### Находки

- **L1 (низкая). `bl.pos_guest(uuid, text)` — межклубный оракул существования гостя по телефону** (`0481_pos_guest.sql`, `server/orders/pos.mjs:resolveGuest`). Ресепшн любого клуба узнаёт, есть ли человек с этим телефоном на платформе, и получает непрозрачный `user_id`. Смягчения: только персонал кассы, без имени и других ПДн, учётка не создаётся, без согласия — NULL. Решение — №121.
- **I1 (инфо).** `bl.booking_due`, `bl.summary_clubs` отдают межклубные id роли `app_api` без фильтра контекста: узкие функции планировщика, наружу недоступны (инвариант 9), `public` лишён execute. Не вешать на пользовательские маршруты.
- **I2 (инфо).** `light.startFromDeposit` сам не проверяет открытую смену — проверяет единственный вызывающий `reception.createDeposit` в той же транзакции. При втором вызывающем продублировать проверку.

### Выдержали (PoC в этой папке)

`isolation.test.mjs` (5), `definer.test.mjs` (11), `money_db.test.mjs` (8), `notify_actions.test.mjs` (7).

- Изоляция: 9 новых таблиц с RLS и FORCE по `ctx_club_id()`, чужой `club_id` при вставке — 42501, DELETE у `app_api` нет, гость видит только свои брони.
- Персонал: приглашение на `owner` запрещено базой; приглашение привязывается только к своему телефону; отзыв гасит членство, PIN и все токены, включая PIN-токен терминала; повторное принятие после отзыва доступ не возвращает.
- Деньги: `createBookingQuote` не больше тарифа (№113), сумма ≤ 0 — отказ; возврат пакета один раз, тронутый — `package_used`; `lot_id` в продаже ставится один раз; отрицательные и нулевые платежи — отказ.
- Уведомления: кнопки — только относительный путь своего сайта (`javascript:`, внешний хост, `//`, `\`, `data:`, CRLF отвергаются), ≤ 5 действий; телефоны в текстах и сводке маскируются; `/availability` без входа не раскрывает имя и телефон брони.
- Чтением кода: старт по брони требует владельца брони и код стола, идемпотентен по `booking_id`; повтор вебхука и две оплаты предоплаты — лишняя возвращается целиком; депозит идемпотентен, возврат не больше внесённого; зачёт не считается приёмом денег, ключ ККТ различает предоплату, зачёт и возврат; чужое предложение листа ожидания не принять; двойного возврата пакета через приложение и кассу нет.
