# M5.8 «Падел-корт» — PoC pentester

Проверка безопасности вида ресурса `padel_court`: цена слота, оплата → свет, игроки, бронь, тарифы и зал, каталог.
Итоги и находки — в отчёте pentester оркестратору; `REPORT.md` записывает оркестратор из этого отчёта (запись файла субагентом инструментом отклонена). Продуктовый код не менялся.

## Что нужно

- Поднятый стенд разработки: `https://localhost:8443` (Caddy), симулятор контроллеров `http://127.0.0.1:18080`,
  эмулятор ЮKassa в контейнере `billiardum-yookassa-emu-1` (управление через `docker exec`, как в `tests/e2e/m1`).
- `ALLOW_DEV_LOGIN=1` и `DEV_ALLOW_ANY_MINUTES=1` на стенде (по умолчанию в разработке).
- Корты сида: `TESTC00001` (устройство 101) и `TESTC00002` (устройство 102) в «Тестовом клубе». Столы 1–8 PoC не трогают.
- К базе стенда, `.env`, секретам и `docker inspect` PoC не обращаются. Гости — `+7999674xxxx`.

находка — `НАХОДКА воспроизведена` и на код выхода не влияет (PoC находки «проходит», пока дефект жив).

node tests/security/m5-8/05-engine-pricing.mjs

node tests/security/m5-8/03-setup-tariffs-hall.mjs

node tests/security/m5-8/09-payment-labels.mjs

Заход 2 корты сида не использует (сценарии 11, 13, 15 — на своём Postgres: `DATABASE_ADMIN_URL=postgres://postgres@127.0.0.1:55432/postgres node --test …`; 12 и 16 — на стенде со своим клубом). Корты нужны по одному (заход 1): `02`, `07`, `09` — корт 101; `04`, `06`, `08`, `10` — корт 102. Параллельно один корт не занимать.

## Следы на стенде

- Свои гости `+7999674xxxx` и клубы «Pentest Padel 58», «Pentest Padel 58 B» (по клубу на запуск `03`), «Pentest Padel 58 C»
  в режиме test: в каталог не попадают, удаления клуба в API нет.
- Сид: брони корта 102 созданы и отменены; `10` оставляет отменённую бронь с предоплатой 3 900 ₽ (эмулятор), которая
  не вернулась по правилу отмены менее чем за 2 часа до начала; заявка ресепшена на корт 102 отклонена; игры на кортах
  закрыты, кортам возвращено «свободен».
- Сид читали и писали входом сидовых сотрудников: владелец `+70000000001` — только чтение журнала (`06`);
  ресепшн `+70000000004` — чтение списка заявок и отклонение своей заявки (`08`).
