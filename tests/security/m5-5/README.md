# Проверка безопасности M5.5 «Сети»

PoC против локального стенда `https://localhost:8443` (API через Caddy, вход для разработки) и против
своего временного Postgres. Итог и находки переданы оркестратору в отчёте pentester (файла `REPORT.md`
в этой папке нет: запись отчёта файлом субагенту запрещена; оркестратор кладёт его сюда сам).

Правила: только свои номера `+7999673xxxx` и свои новые тестовые клубы; база стенда, `.env`, секреты и
клуб сида не трогаются. Каждая строка вывода — утверждение безопасного поведения: `PASS` — защита
держится, `FAIL` — находка (см. отчёт pentester). Код возврата 1, если есть `FAIL`.

## Запуск

Стенд должен быть поднят (`npm run dev`). Хелперы берутся из `tests/e2e/m1` и `tests/e2e/m5`.

    node tests/security/m5-5/01-network-isolation.test.mjs

Вход для разработки ограничен 30 запросами в минуту; хелпер ждёт при 429, но весь набор лучше
запускать с паузой 20 секунд между файлами. Телефоны выбираются от текущего времени, чтобы повторные
прогоны не упирались в лимит 3 тестовых клубов на пользователя. Клубы и сети, созданные прогонами,
остаются на стенде (удаления через API нет).

## Сценарии на своём Postgres (09, 15, 16, 17)

Поднять кластер (от имени не-root пользователя) и применить миграции, как ниже; `15`, `16`, `17` берут адрес из
`DATABASE_ADMIN_URL` и отказываются работать не с `127.0.0.1:55xxx`:

    DATABASE_ADMIN_URL=postgres://postgres@127.0.0.1:55432/postgres node --test tests/security/m5-5/17-network-terminals-db.test.mjs

## Сценарий 09: свой временный Postgres

Сценарий работает только с адресами, которые вы задали сами, и отказывается работать не с
`127.0.0.1:55xxx`. Поднять кластер и применить миграции репозитория:

    initdb -D <каталог> -A trust -U postgres -E UTF8 --locale=C.UTF-8
    pg_ctl -D <каталог> -o "-p 55432 -k <каталог> -c listen_addresses=127.0.0.1" -l <каталог>/log -w start
    # миграции: supabase/lib/db.mjs migrate({ connectionString, appPassword })

    POC_PG_ADMIN_URL=postgres://postgres@127.0.0.1:55432/postgres \
    POC_PG_APP_URL=postgres://app_api:<пароль>@127.0.0.1:55432/postgres \
    node tests/security/m5-5/09-db-guards.test.mjs

Кодировка кластера — UTF-8 (в `SQL_ASCII` сид не проходит проверку имени). После прогона кластер
останавливают и удаляют. Без переменных сценарий пропускается (`SKIP`).
