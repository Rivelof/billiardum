## Не проверено

- Реальная доставка MAX, Telegram, Web Push: каналы не настроены; цепочка проверена настоящим обработчиком доставки с подменой адаптеров.
- Сводка «в 10:00» по часам живого сервера: проверено планировщиком с поддельными часами.
- Удержание 30 % — на сокращённом удержании 2 минуты.
- p95 «оплата → свет» при старте по брони — одиночные замеры, около 100 мс.

## Что сделано на стенде

- Закрыта служебная смена №46 (живая проверка frontend) ресепшеном через API: факт = ожидаемому 3 100 ₽, расхождение 0, комментарий «служебная смена стенда».
- Правила брони клуба и `booking_forfeit_percent` меняются на время прогона и возвращаются (сейчас: шаг 30, упреждение 15, минимум 60, предоплата full, удержание 30 мин, 100 %).
- Синтетические гости `+7999…`, брони, пакеты, свои смены (закрыты без расхождения), отозванный сотрудник, терминал «Терминал e2e M3»; синтетические id MAX и Telegram гостя T21 (сбрасываются); режим эмулятора ЮKassa `fail_next` (сбрасывается).
