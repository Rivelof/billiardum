## Дефекты

- **Д1 — средний, light.** Конец игры при ждущей брони: `state.reserved` уходит раньше `session.stop`, контроллер отклоняет обе (`wrong_session`), свет гасит только сверка с ложной причиной `not_paid`. `server/sessions/service.mjs:693–698`, `server/devices/store.mjs:133`.
- **Д2 — средний, стенд.** `yookassa-emu` работал на коде до M3 (`/v3/receipts` → 404). Исправлено перезапуском; `npm run dev` не перезапускает эмуляторы при смене кода. Попутно: отказ ЮKassa 4xx на чек зачёта — `failed` без повтора.
- **Д3 — низкий/средний, money, инвариант 8.** Уведомление владельцу о возврате пакета без суммы и причины. `server/packages/balance.mjs:164`.
- **Д4 — низкий.** Сводка считает действия системы «ручными». `server/reports/queries.mjs:202–203`.
- **Д5 — низкий.** «за 2 минут» без `plural()`. `server/bookings/service.mjs:790–791`.
- **Д6 — низкий.** Игра по брони на 30–59 с дольше конца брони; опоздавший платит за округлённую вверх минуту. `server/bookings/service.mjs:527, 603`.
- **Д7 — низкий.** Бронь принимается ближе 5 минут к концу текущей игры. `server/bookings/service.mjs:193`.

Наблюдения: предложение из очереди стол не держит; `channels.max: true` при заглушке MAX; депозит считается с минимумом тарифа.

## Не проверено

- Реальная доставка MAX, Telegram, Web Push — нет dev-подмены канала.
- Сводка «10:00» на часах живого сервера — проверена планировщиком с поддельными часами.
- 30 % проверено на удержании 2 минуты.
- p95 старта по брони — одиночные замеры.
