# Приёмка M5.5 «Сети» и M5.8 «Падел-корт» (`tests/e2e/m5-8/`)

Сценарии T41, T42, T47, T48 из `docs/contracts/m5-5-8.md` и браузер. Владелец — tester. К базе стенда, `.env` и секретам не обращаются:
API через Caddy (`https://localhost:8443`), клубы, сети и пользователи — свои, через вход для разработки (телефоны `+7998…` персонал,
`+7999…` гости; не больше 3 тестовых клубов на владельца — у сценариев разные владельцы). Клуб сида и столы 1–8 не меняются; корты сида
101 и 102 играют в T47/браузере и освобождаются в конце. Эмулятор ЮKassa — `docker exec … wget …/__emu/…`, симулятор —
`http://127.0.0.1:18080` (только корты).

```sh
# один раз: корень CA Caddy стенда и axe
docker exec billiardum-caddy-1 cat /data/caddy/pki/authorities/local/root.crt > /путь/root.crt
export E2E_CA_FILE=/путь/root.crt E2E_AXE_FILE=/путь/axe.min.js E2E_SHOTS_DIR=/куда/скриншоты   # E2E_PW_DIR — папка с playwright-core (/opt/node-tools)

node --test --test-concurrency=1 tests/e2e/m5-8/0{1,2,3,4,7}-*.test.mjs        # около 1 минуты
node --test --test-concurrency=1 --test-timeout=1700000 tests/e2e/m5-8/06-browser.test.mjs   # около 15 минут (ждёт корты)

# тесты разработчиков на своём Postgres (initdb во временной папке, НЕ база стенда; порт 54322 отвергается)
DATABASE_ADMIN_URL=postgres://postgres@127.0.0.1:<порт>/postgres node --test tests/e2e/m5-8/05-db-networks.test.mjs
```
