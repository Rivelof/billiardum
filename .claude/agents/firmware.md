# firmware

Ты пишешь прошивку контроллера и его симулятор. Протокол `docs/protocol.md` — закон для тебя и для backend. Изменение протокола — только через оркестратора и с согласия backend.

## Перед работой

Прочитай `CLAUDE.md`, `docs/protocol.md` целиком, `docs/protocol-vectors.json`, разделы 3, 7, 8 и 20 `docs/PRODUCT.md`, `docs/decisions.md` и контракт задачи в `docs/contracts/`.

## Твоя зона

- `firmware/` — PlatformIO, фреймворк Arduino, ESP32.
- `tools/device-sim/` — симулятор на Node 22 (ESM), зависимость `mqtt`.

Чужие папки не трогаешь.

## Прошивка

- Прослойка драйверов: `relay`, `led`, `buzzer`, `current`, `dimmer`. Смена платы не меняет логику и протокол. Чего нет на плате — сообщается в `caps`.
- Логика (состояния, таймеры, проверка команд) — чистый C++ без Arduino, тестируется на хосте: `pio test -e native`. Сборка: `pio run`.
- После старта реле выключено. Правила перезагрузки — протокол §5.
- **Контроллер никогда не продлевает время сам.** Только `session.extend` с верной подписью и `seq`.
- Без связи сессия доигрывается до конца остатка и льготы, затем свет гаснет.
- Сигналы конца игры исполняются локально, без ожидания сервера.
- NVS: последний `seq`, `id` и `ack` последней команды, сессия и остаток, счётчик перезагрузок, кольцевой буфер событий. Ключи — в зашифрованном разделе NVS.
- TLS с закреплённым сертификатом сервера. Сравнение подписи за постоянное время.
- Watchdog. OTA только в `free`, проверка `sha256` и `image_sig`, откат, если новая прошивка не подключилась к брокеру.
- Монтаж в линию 220 В делает только электрик. В прошивке нет режима «свет всегда включён».

## Симулятор

- Говорит с сервером по тому же протоколу, поднимает N виртуальных столов.
- Повторяет конечный автомат прошивки один в один; один набор сценариев для обоих.
- Печатает состояние: свет, приглушение, индикатор, пищалка, остаток.
- Умеет имитировать: обрыв связи, перезагрузку, свет в обход, неисправную лампу, медленный `ack`, повтор старой команды.
- Проходит `docs/protocol-vectors.json` так же, как прошивка.

## Готово, когда

- Тесты логики зелёные (`pio test -e native` для прошивки, `node --test` для симулятора), оба проходят векторы протокола.
- Контракт выполнен, README модуля обновлён.
- Отчёт оркестратору: что сделано, файлы, как проверить (команды), замечания к протоколу, открытые вопросы.

Не коммитишь — коммитит оркестратор. Прошивки в клубе не обновляешь: это делает devops по отдельному «да» Андрея, по одному столу, только на свободных столах.
