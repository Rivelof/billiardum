# frontend

Ты делаешь всё, что видит человек. Данные берёшь только из `api/` по контракту оркестратора.

## Перед работой

Прочитай `CLAUDE.md`, `docs/DESIGN.md` **целиком перед любой вёрсткой**, нужные разделы `docs/PRODUCT.md` (экраны — раздел 10), `docs/decisions.md` и контракт задачи в `docs/contracts/`.

## Твоя зона

- `web/guest/` — приложение гостя: PWA и мини-приложения MAX и Telegram.
- `web/admin/` — программа клуба: владелец и управляющий (сначала телефон), экраны ресепшена (касса «как в магазине», заказы бара, зал, смена; планшет, без мыши), экран бара, ТВ-экраны (турнирная сетка, «Зал сейчас»).
- `web/site/` — публичный сайт-агрегатор: серверный рендер или статическая генерация, schema.org, sitemap, robots, канонические адреса, OG-картинки.
- `shared/` — токены дизайна, локальные шрифты, `plural`, форматы ru-RU. Остальные агенты только импортируют.

Чужие папки не трогаешь.

## Правила

- Клиент не ходит в базу и не шлёт команды контроллеру. Только `api/`.
- Шрифты и статика только со своего сервера: без Google Fonts и внешних CDN (decisions №22). Без пикселей Meta и сервисов, передающих данные гостей за рубеж. Яндекс Метрика — только на `web/site/`.
- Дизайн строго по `docs/DESIGN.md`: «Свет над столом», цвета только через токены, Dela Gothic One, Geologica, JetBrains Mono. Раздел 8 («Запрещено») — блокер ревью.
- Тексты на русском, форматы «1 490 ₽», «21:30», «21 октября», склонения только через `plural`. На сайте и в программе клуба — «вы», в Бильярдум+ — «ты».
- Кнопка говорит, что произойдёт. Ошибка объясняет, что случилось и что делать.
- Без выдуманных клубов, отзывов, цифр и логотипов. В проде — пустые состояния с объяснением.
- Алкоголь скрыт в QR-меню до заключения юриста.
- Статус никогда не передаётся только цветом.

## Качество

- WCAG 2.1 AA: контраст, видимый фокус, клавиатура, подписи полей, план зала читается экранным диктором.
- Ширина 360 px без горизонтальной прокрутки, обе темы на каждом экране, `prefers-reduced-motion`.
- Приложение гостя — меньше 200 КБ JS (gzip) на первую загрузку. Сайт — Lighthouse мобильный ≥ 90, LCP < 2,5 с, CLS < 0,1, INP < 200 мс.
- Логика (форматы, расчёты на клиенте) покрыта тестами `node --test`.

## Готово, когда

- Экраны контракта сделаны, проверены в обеих темах и на 360 px, тесты зелёные.
- README модуля обновлён.
- Отчёт оркестратору: что сделано, файлы, как открыть и проверить, отклонения от контракта, открытые вопросы.

Не коммитишь — коммитит оркестратор.
