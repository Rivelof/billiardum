## 1. Главный «ДАШБОРД» (`/dashboard/`) — screens/01-dashboard

**Фильтры:** период «По дням / По месяцам / По годам» + дата/диапазон, кнопки «Применить», «Сброс».
Плашка-подсказка: «данные из ежедневного сбора статистики по всем клубам за период …».

**Плитки KPI («Данные за период»)** — у каждой иконка «i» с пояснением, у некоторых бейдж-процент:

| Плитка в LANGAME | Для бильярда |
|---|---|
| Итоговая выручка | Итоговая выручка |
| Всего гостей | Всего гостей |
| Регистраций (+% от гостей) | Регистраций |
| Сессий | Игр (сессий за столами) |
| Уникальных сессий (+%) | Уникальных гостей за столами |
| Средний чек сеанса | Средний чек игры |
| Средний чек пополнений | Средний чек пополнения депозита |
| Средний чек бара | Средний чек бара/кухни |
| Кол-во активных ПК за период | Кол-во активных столов |
| Кол-во активных ТВ за период | Кол-во активных VIP-комнат / спец. столов |
| Выручка с устройства в день | Выручка со стола в день |
| Выручка с ТВ в день | Выручка с VIP-комнаты в день |
| Выручка бара (+% от выручки) | Выручка бара/кухни (+%) |
| Ручные пополнения (+%) | Ручные пополнения |
| Сумма / кол-во пополнений через бонусную кассу | то же |
| Сумма / кол-во пополнений бонусов | Начислено бонусов |

**Таблицы (с «Экспорт в Excel»):**
- Ежедневная таблица средних списаний: ср. чек сеанса на ПК / на ТВ / общий / ср. чек бара.
- Ежедневная таблица средних пополнений: наличный / безналичный / ручные / общий.

**Графики (у каждого кнопка «Экспорт»):**
1. Ежедневный график гостей (кол-во): всего гостей, регистрации — столбцы.
2. Ежедневный график сессий: кол-во сессий, уникальные.
3. Гости и сессии в процентах: % регистраций, % уникальных сессий.
4. Кольцо «Гости за период»: старые / новые.
5. Кольцо «Сессии за период»: уникальные / остальные.
6. Ежедневный график средних списаний (4 серии).
7. Ежедневный график средних пополнений (4 серии).
8. Ежедневный график загрузки устройств: % общий / ПК / ТВ.
9. Кольцо «Загрузка в часах за период»: максимальная (ёмкость) / ПК / ТВ / **нереализованная**.

## 2. «Дашборд Business» (`/dashboard_business/`, React в iframe) — screens/02-dashboard-business

Сверху два выпадающих списка: **режим** (Сводка / Деньги / Балансы / Статус зала) и **клуб** («Мой центр»).
Это мобильный «дашборд владельца», самый близкий к тому, что нужно в бильярде.

**Сводка**
- Деньги: выручка за сутки, расходы за сутки.
- Баланс аккаунтов (сумма, % от выручки), «Еда и услуги» (сумма, %) — кольцевые индикаторы.
- Балансы: сводные ДС, сводные бонусы.
- Статус зала: занято / свободно / тех. режим / разблок / соединение + полоса-индикатор;
  текущая загрузка (7/31, %), средняя загрузка за сутки (%).
- Администратор в смене: ФИО, логин, начало смены.

**Деньги**
- Структура выручки: баланс аккаунтов / еда и услуги (раскрываются).
- Наличные vs безналичные (полосы с %).
- По источникам: АДМИН (наличные, карты) · ПРИЛОЖЕНИЕ (карты, QR) · ЛИЧНЫЙ КАБИНЕТ (карты, QR) · ТЕРМИНАЛ (наличные, QR, карты).
- Расходы.
- Наличных в кассе: на начало суток, за сутки, расходы, инкассации.
- Отчёты: переключатель «Сутки», столбчатый график выручки за 30 дней, текущий день выделен;
  ниже аккордеоны «Выручка», «Распределение по структуре», «по типу и источнику», «Расходы».

**Балансы**
- Пополнения (деньгами / бонусами), Списания, Возвраты — каждое раскрывается.
- Сводный баланс дня: деньги (пополнение, списание, возврат), бонусы (то же).
- Суммы балансов: деньги, бонусы — общий остаток на счетах гостей.
- Отчёты (график).

**Статус зала**
- Сводная информация по зонам: Эксклюзив 0/0, ТВ 0/1, Дуо 0/4, Стандарт 1/6, VIP 6/21; текущая и средняя загрузка.
- Карточка на каждую зону: текущая загрузка X/Y, % загрузки, деньги, бонусы.
- Гости: всего / новые / повторные.
- Регистрации: через приложение / на месте.
- Бронирования: всего / отыгранные / неотыгранные.
- Сессии: уникальные / повторные.
- Отчёты: графики гостей, регистраций, бронирований, сессий, загрузки клуба.

## 4. Предлагаемый дашборд для бильярдного клуба

Основа: «Дашборд Business» (мобильный, для владельца) + KPI и графики главного «Дашборда».

**Фильтры (вверху, закреплены):** период (сегодня / вчера / неделя / месяц / произвольный) · клуб · тип стола.

**Блок 1. KPI за период**
Выручка всего · из неё столы / бар-кухня / прокат и услуги (с %) · гости (новые / повторные) ·
игр за столами · средний чек игры · средний чек бара · выручка со стола в день · загрузка столов, % ·
средняя стоимость часа · начислено и списано бонусов.

**Блок 2. Статус зала (в реальном времени)**
По типам столов (Русский бильярд / Пул / Снукер / VIP-комната): занято X/Y, бронь, на обслуживании;
текущая загрузка и средняя за сутки; администратор в смене и время начала смены.
Плюс схема зала (как «Генератор карт»): цвет стола = свободен / играют / бронь / обслуживание.

**Блок 3. Деньги**
Структура выручки (столы / бар / прочее) · наличные и безнал · каналы (админ, приложение, онлайн-бронь, терминал) ·
касса: наличные на начало суток, за сутки, расходы, инкассации · график выручки за 30 дней.

**Блок 4. Брони и гости**
Брони: всего / пришли / не пришли (неявки — для бильярда важнее, чем в компьютерном клубе) · средний срок от брони до игры ·
гости: новые / повторные / реактивированные / потерянные · регистрации · частота визитов · Retention.

**Блок 5. Графики**
1. Выручка по дням (столбцы, разбивка столы / бар).
2. Загрузка столов по дням (%, по типам столов).
3. **Тепловая карта «день недели × час»** — в LANGAME её нет, а для расписания и цен она главная.
4. Кольцо «Загрузка в часах»: ёмкость / сыграно / нереализовано.
5. Средний чек игры и бара по дням.

**Что убрать из модели LANGAME:** процессы, заморозку, лаунчеры, игровые аккаунты, температуру ПК, hosts, энергосбережение, QR-вход.
**Что добавить:** прокат и выдача киёв (залог), обслуживание столов (перетяжка сукна, замена шаров) вместо «тех. режима»,
турниры и рейтинг игроков, тренер/инструктор как услуга с почасовой оплатой, депозит или предоплата за VIP-комнату,
включение света над столом по старту сессии (аналог разблокировки ПК).

## 5. Что не снято скриншотами

Панель браузера скрылась во время съёмки, поэтому по разделам **Рассылки, Доп. модули, Аналитика, Тех. статистика,
Документы, Статистика/Бронирование, Тикеты** есть только список страниц из меню (раздел 3), без скриншотов.
