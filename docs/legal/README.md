# Юридические документы

Готовит юрист, тексты кладутся сюда. Код и интерфейс ссылаются на эти файлы, а не дублируют их.

- `privacy.md` — политика обработки персональных данных (152‑ФЗ).
- `consent.md` — согласие гостя на обработку персональных данных (отдельный флажок).
- `offer-clubs.md` — оферта для клубов (подписка на программу).
- `terms-guests.md` — пользовательское соглашение для гостей.
- `refunds.md` — правила возврата за игру, бронь и взносы турниров.

При изменении оплаты или хранения данных гостей проверить, что эти тексты говорят то же самое.
