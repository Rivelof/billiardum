# Контракты M4 «Сайт-агрегатор, Бильярдум+, турниры»

Автор: оркестратор. Зафиксирован 23.10.2026 после закрытия M3, проверки бэкенда и редизайна №127 (решения №131–142). Отклонение — только через оркестратора.

Цель M4 (ROADMAP): публичный сайт-агрегатор с серверным рендером и SEO; каталог клубов без парсинга справочников, «Подтвердить клуб», «Добавить клуб», заявки гостей в клубы без программы с передачей оператору (T25); заявки клубов на программу (`leads`) с уведомлением Андрею; Бильярдум+: профиль, рейтинг Эло с подтверждением партий без персонала (T22, T23), таблицы, «Ищу соперника», друзья, достижения; турниры: создание, запись со взносом, посев, сетка, блокировка столов, счёт от игроков, ТВ-экран (T24). Приёмка: T22–T25, Lighthouse мобильный ≥ 90 на главной, странице города и клуба, 360 px без горизонтальной прокрутки, обе темы.

Ограничения среды прежние: ЮKassa, MAX и Telegram — эмуляторы и заглушки. Яндекс Метрика и Вебмастер — только подготовка (идентификаторы из `.env`, по умолчанию выключено), реальное подключение — по домену Андрея.

## 1. Решения M4

1. **`web/site/` — отдельный сервис серверного рендера** (Node 22, Preact `renderToString`, без фреймворка), процесс `site` в Compose. В базу не ходит: данные берёт из публичного API сервера по внутренней сети, кэширует ответы на 60 с и отдаёт готовый HTML. Интерактив (фильтры, план зала вживую) — небольшие острова на клиенте, бюджет JS страницы ≤ 50 КБ gzip.
2. **Адреса** по PRODUCT §15: `/`, `/{город}/`, `/{город}/{клуб}/`, `/turniry/`, `/turniry/{id}/`, `/rejting/`, `/plus/`, `/dlya-klubov/`, `/dlya-biznesa/`, `/zhurnal/`, `/zhurnal/{slug}/`, `/t/{код}`. Слаги — латиница (транслит), уникальны; город — по справочнику городов платформы, клуб — внутри города.
3. **Карточка клуба в агрегаторе — `club_public`**: статус `listed` (добавлена командой с согласия клуба или владельцем через «Добавить клуб», не подтверждена), `claimed` (владелец подтвердил права), `platform` (клуб работает в программе — данные живые: план зала, свободно сейчас, цены, бронь). Без программы — пометка «Бронь по заявке».
4. **Заявка гостя в клуб без программы** (`club_requests`): уходит клубу в его канал (MAX/Telegram/телефон из карточки, через уведомления). Нет ответа «принял/отказал» за 15 минут — заявка уходит оператору платформы. Гостю — статус заявки. Это T25.
5. **Роли платформы**: `platform_operator` (заявки гостей и клубов, модерация карточек и отзывов) и `platform_admin` (Андрей: всё платформенное). Хранятся отдельно от `club_members`, действия — в журнал платформы.
6. **Заявки клубов на программу (`leads`)**: форма на `/dlya-klubov/` (имя, клуб, город, телефон, число столов, согласие) → запись, уведомление Андрею (platform_admin) по цепочке уведомлений, статус воронки. Защита от спама: лимит по IP и простая проверка (скрытое поле + время заполнения), без внешних капч.
7. **Рейтинг Эло** по PRODUCT §13: дисциплины `pyramid`, `pool`, `snooker`; старт 1 200; K = 40 первые 20 партий, затем 20; турнирные ×1,5. Партия засчитывается, если оба игрока — участники одной активной (или закрытой не более 30 минут назад) сессии стола клуба на платформе, оба подтвердили результат в приложении в течение 30 минут, и это не больше третьей засчитанной партии этой пары за рабочие сутки клуба (T23). Спор → управляющему клуба, решение в журнале. Сезон — календарный месяц по Москве плюс общий рейтинг. Уровни — по PRODUCT §13.
8. **Профиль игрока** по умолчанию показывает ник, уровень и рейтинг; остальное — по выбору игрока. Ник уникален, без телефона и фамилии по умолчанию. «Друзья в клубе сейчас» — только с разрешения друга.
9. **«Ищу соперника»**: дисциплина, время, клубы; подбор ±150 рейтинга; приглашение «Сыграем?» → после принятия общая бронь (через bookings, бронь на двоих). Нет приглашений спамом: лимит 10 в день.
10. **Достижения** — только проверяемые по данным (PRODUCT §13), выдаются фоновой проверкой после закрытых сессий, матчей и турниров; каждое один раз.
11. **Турниры (M4)**: форматы — олимпийская система и группы с плей-офф; «до двух поражений» — M5. Матчи до N побед, в пирамиде партия до 8 шаров. Ограничение по рейтингу: запись с рейтингом выше лимита — отказ с объяснением (T24). Взнос — платёж ЮKassa вида `tournament` с чеком; возврат: до начала — целиком (отмена игроком до закрытия записи), при отмене турнира клубом — целиком всем, после начала — нет. Посев по рейтингу дисциплины. Столы турнира блокируются на время матчей удержанием light `source: 'tournament'`; брони и игры по QR на этих столах в это время не принимаются. Счёт вносят оба игрока, подтверждают; расхождение — организатору; исправление организатора с причиной в журнал. Результаты меняют рейтинг (×1,5). ТВ-экран сетки обновляется по SSE.
12. **Отзывы** — только от гостей с сессией или бронью в этом клубе за последние 90 дней, один на гостя и клуб (можно изменить). Клуб может ответить; жалоба → оператору. Оценка 1–5 и текст до 1 000 символов; ПДн в тексте не публикуются (маскирование телефонов).
13. **Журнал (`/zhurnal/`)** — статьи из файлов Markdown в репозитории (`web/site/content/zhurnal/`), без CMS. В проде пусто, пока Андрей не добавит статьи; выдуманных статей нет.
14. **Аналитика**: только Яндекс Метрика на сайте, включается переменной `.env`, без Вебвизора на формах; в приложениях гостя и клуба аналитики нет. Пиксели Meta и иностранные счётчики запрещены.
15. **SEO**: schema.org (`SportsActivityLocation`, `SportsEvent`, `BreadcrumbList`, `Organization`), `sitemap.xml`, `robots.txt`, канонические адреса, OG-картинки клубов и турниров (генерация SVG→PNG на сервере сайта, кэш), `lang="ru"`, мета-описания. LCP < 2,5 с, CLS < 0,1, INP < 200 мс.

## 5. Сценарии и приёмка

T22 два игрока подтверждают партию 8:5 → рейтинг пересчитан у обоих. T23 четвёртая партия пары за день → в рейтинг не засчитана (сохранена с причиной). T24 запись на турнир с рейтингом выше лимита → отказ с объяснением. T25 клуб без программы, заявка гостя → в клуб, через 15 минут без ответа — оператору. Плюс: страница клуба на платформе показывает свободные столы вживую; турнир — запись со взносом и чеком, посев, сетка на ТВ, счёт от игроков, рейтинг ×1,5; столы турнира заблокированы; отзыв только после игры; lead → уведомление Андрею; SEO-разметка валидна; Lighthouse мобильный ≥ 90 (главная, город, клуб); 360 px, обе темы.
